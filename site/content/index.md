# LinTi

LinTi checks TM1 TurboIntegrator scripts for formatting mistakes, naming conventions, and subtle code-quality issues. The playground and the rule reference run entirely in your browser.

::u-button{to="/playground" icon="i-lucide-square-terminal"}
Lint a process in your browser
::

::u-button{to="/rules" icon="i-lucide-list-filter" variant="outline"}
Explore the rules
::

Install the CLI with `pip install linti`, or explore the [source on GitHub](https://github.com/deutschebahn/linti).
