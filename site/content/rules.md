Search and filter the rules below. Pick an example, edit its TI code, and run that rule locally in your browser. Code is not sent to a LinTi server.

Expand the configuration panel to see which settings the example uses: either LinTi's defaults, the example's YAML, or your current local configuration. To customize it, open the [configurator](/config), then return to test the rule here. You can save a variant there if you want to keep it.
