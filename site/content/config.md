---
title: Configurator
description: Build a linti.yaml for your project from a use case, then fine-tune every rule.
---

Use the add button to name a new configuration and start with an empty `linti.yaml`, Recommended, Strict CI gate, or Planning Analytics v12 migration. Adjust the rules or edit the YAML directly; the form follows along. **Save configuration** stores it directly in this browser. Use the switcher to move between configurations; **Manage configurations** offers duplicate, rename, export, and import.

You can download the YAML for your project or try your draft in the playground and rule reference. A share link opens as a draft that you can save if you like.
