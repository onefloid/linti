---
title: Playground
description: Paste a whole TI process, lint it, and apply auto-fixes in your browser.
---

Write or paste a TI process. The editor supports `.ti` files (plain or with `#region` sections), PA code format and YAML format. The format is detected automatically.

Everything runs locally in your browser via Pyodide: your code is never sent to a server.

The active configuration from the [configurator](/config) is used here automatically. Edit and save configurations in the configurator.

::process-playground
::
