---
title: Configurator
description: Build a linti.yaml for your project from a use case, then fine-tune every rule.
---

Use the add button to add and name a new configuration. You can choose a template of your choice. Recommended is selected by default and uses LinTi's standard settings. Adjust the rules or edit the YAML directly; the form follows along. **Save configuration** stores it directly in this browser. Use the switcher to move between configurations; **Manage configurations** offers duplicate, rename, export, and import.

You can download the YAML for your project or try your draft in the playground. A share link opens a configuration as a draft that you can save if you like.
